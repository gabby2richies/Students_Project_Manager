This a simple Python Student Management System,
that helps organise the students records, assess the scores and calculate the  of the student.
It also helps in other functionalities like:
  - Register new students with their ID, name, age, and course.
  - View all registered students.
  - Search for students using their ID.
  - Update student information.
  - Delete student records after confirmation.
  - Record assessment scores and calculate averages.
  - Assign grades based on average scores.
  - Save and load student records using JSON.
  - Export student information and scores to CSV.
